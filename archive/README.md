# Archive

Ce dossier contient l'historique technique (anciens modeles, scripts de test, autosaves).

## Objectif

- Preserver les anciennes versions sans polluer le flux principal.
- Permettre de retrouver rapidement une hypothese/test historique.

## Contenu typique

- anciens `.slx`/`.slxc`
- scripts de test non utilises dans le pipeline principal
- autosaves

## Regle

Aucun element de ce dossier ne doit etre une dependance obligatoire du pipeline courant.
