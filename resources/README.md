# Resources

Ce dossier contient des ressources internes du projet MATLAB (`.prj`) generees par MATLAB.

## Important

- `resources/project/` est gere par MATLAB.
- Eviter de modifier ces fichiers manuellement.
- Les changements apparaissent lors de modifications de configuration du projet.

## Quand versionner

Versionner uniquement si vous voulez partager explicitement les reglages projet entre membres d'equipe.
